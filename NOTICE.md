# Origin of the code

This project is a fork and a large further development of earlier open source work, all under the MIT License (see LICENSE, the original copyright line is kept as it is):

- fjfricke/ha-openai-realtime (Felix Fricke): original Voice PE firmware component and WebSocket bridge idea.
- just-jeb/ha-openai-realtime-voice: the version this fork was taken from.
- esphome/home-assistant-voice-pe: the Voice PE base firmware the ESPHome config builds on.

Changes and additions since the fork (Leyla features, server modules, wake word, announcements and so on) are by Metin Taskiran. The upstream LICENSE files contain no author names, only "Copyright (c) 2024-2025".
